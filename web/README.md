# Travel Agent Lab · 本地前端（v0.4.0）

React + TypeScript + Vite 实现的本地单用户界面，对接仓库根目录的 FastAPI 后端。页面分三栏：左侧聊天列表，中间消息、可折叠需求表单与逐日行程，右侧高德地图。分隔条可以拖动。

## 运行前准备

1. **后端**：在仓库根目录安装依赖（参见根目录 README），然后启动 FastAPI：

   ```powershell
   python -m uvicorn api:app --host 127.0.0.1 --port 8000
   ```

   Windows 上若 `python3` 不可用，请使用 `python`。后端需要根目录 `.env` 中的模型与高德 Web 服务 Key，这些密钥不要复制到前端。

2. **前端依赖**：在 `web/` 目录安装一次：

   ```powershell
   cd web
   npm ci
   ```

3. **高德 JS API Key**（仅地图需要）：在高德开放平台为本项目申请 **Web端（JS API）** 类型的 Key，并把域名白名单设为 `localhost` 和 `127.0.0.1`。然后在 `web/` 下创建 `.env.local`：

   ```dotenv
   VITE_AMAP_JS_KEY=你的JS Key
   # 按高德控制台对此 JS Key 的要求配置：
   VITE_AMAP_SECURITY_CODE=安全密钥
   ```

   `.env.local` 已被 Git 忽略，请不要把真实 Key 写入 `.env.example` 或其他会提交的文件。不配置时，页面仍可用，地图区域会显示提示，地点顺序以文字列出。

   `VITE_` 配置会进入浏览器代码，不能当作后端秘密存储。当前仅供本地开发；这里的 JS Key 与后端 `AMAP_API_KEY` 分开配置，不填入模型或 Tavily 密钥。

## 启动

```powershell
cd web
npm run dev
```

浏览器打开 `http://127.0.0.1:5173`。开发服务器把 `/api` 转发到 `127.0.0.1:8000`，因此不需要修改后端的 CORS 设置。

后端文档为 [Swagger UI](http://127.0.0.1:8000/docs) 和 [ReDoc](http://127.0.0.1:8000/redoc)。若 Vite 因端口占用选择其他端口，以终端输出为准。关机后需要重新启动前后端两个进程。

修改 `.env.local` 后需要**重启** `npm run dev`，Vite 只在启动时读取环境变量。

## 使用

1. 点击左侧“＋ 新聊天”，立即创建并选中一张“新的旅游规划”卡片。切换聊天时保留各自消息、输入草稿和表单。
2. 在底部输入旅行需求并发送，调用模型解析后填入表单，显示缺失项或问题；不会自动生成行程。也可直接展开“旅行需求表单”填写。
3. 解析出目的地后，聊天自动命名为“目的地旅游攻略”；直接填写表单并生成行程也会更新自动标题。右键卡片可重命名，手动标题不会被后续自动命名覆盖。
4. 确认目的地、出发日期、天数**或**结束日期（二选一），以及可选的人数、预算、偏好，然后点击“生成行程”。生成中禁用提交按钮并显示等待提示；失败时展示原因。
5. 生成后查看逐日活动时间、地点、交通段、天气和费用；无预报、未知费用及未知耗时均有说明。
6. 右侧地图按天切换，按后端 map_days 绘制编号地点与虚线，并显示“地点顺序示意线，非实际道路路线”。地图随容器宽度调整。
7. 点击“保存当前行程”仅将行程标记为后端当前进程内已保存。左侧聊天切换使用页面缓存，不调用 GET 读取；如需验证服务端读取，在 `/docs` 中使用 `GET /api/plans/{plan_id}`。

自然语言解析和生成行程分别调用模型，可能产生费用。解析只使用本次输入；已生成行程中的输入框会提示新建聊天，不执行行程编辑。

## 边界

- 保存与读取只在**当前后端进程的内存**中有效。重启后端后，旧 plan_id 会返回 404。
- 聊天标题、消息、草稿和历史列表只保存在当前页面内存中，刷新页面后清空；后端重启不会主动清空页面缓存。
- 本版没有编辑、删除、账号或跨重启持久化。
- 示意线不表示实际路线、耗时或距离；前端不计算这些信息。

## 检查

```powershell
cd web
npx tsc -b         # 类型检查
npm run build      # 生产构建
npm run lint       # oxlint
```

构建（包含 TypeScript 检查）和 lint 已通过。目前没有入库的前端自动化测试套件；开发中使用的临时 Node 脚本不在仓库中。项目作者报告自然语言填表、地图日期与地点顺序、三栏拖动、新聊天、自动命名及右键重命名通过。真实服务的保存、GET 读取和重启失效联合验收暂缓；不能把前端缓存切换视为服务端读取验证。
